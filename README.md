# Draw Buddy

Draw Buddy is a downloadable consumer app for exploring lottery draw statistics. It covers NY Quick Draw, Powerball, and Mega Millions, with number synthesis, an interactive heatmap, scratch-off expected-value tools, and a personal play history.

This repository is the single-page preview (`index.html`: vanilla JavaScript, Tailwind from a CDN, and Supabase), published with GitHub Pages.

## Pricing

A player pays for Draw Buddy with one subscription. Both plans unlock the same tools.

| Plan | Price |
| --- | --- |
| Monthly | $1.99 per month |
| Annual | $17 per year |

Annual saves $6.88 versus paying monthly ($1.99 × 12 = $23.88), about 29% off.

Checkout buttons in the page are placeholders that still point at a Stripe test Payment Link. Billing for the downloadable app is expected to use App Store and Google Play in-app subscriptions.

## Play responsibly

Draw Buddy is a statistical entertainment tool. It does not guarantee winnings. Odds, lookback weights, and simulations are for education and entertainment only.
